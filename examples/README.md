# Examples

This folder contains optional example implementations and integrations.

## Demo Mode (`demo/`)

Demo mode allows visitors to try Blank Inbox without requiring real email provider API keys or webhook configuration.

**Location**: `examples/demo/`

**Documentation**: See [examples/demo/README.md](demo/README.md) for complete setup instructions.

**Note**: Demo mode is completely optional. If you're forking or copying this repository and don't need demo functionality, you can safely ignore or delete the `examples/demo/` folder.
